# CLI Reference

## Commands

The package registers four request→response tools under `axm.tools`. The unified
`axm` CLI discovers these entry points and derives their arguments from each
tool's `execute()` signature; there is no package-specific CLI facade.

### `axm audit`

Audit a project's code quality against the AXM standard.

```bash
axm audit [PATH] --json-output [--category CATEGORY]
```

### `axm audit_test`

Run tests and return a fail-closed structured report.

```bash
axm audit_test [PATH] [--files FILES] [--markers MARKERS] [--stop-on-first]
```

### `axm audit_fix`

Plan or apply the deterministic test-suite reorganisation pipeline.

```bash
axm audit_fix [PATH] [--apply] [--rules RULE_IDS]
```

### `axm doc_gate`

Validate a MkDocs documentation build and return structured findings.

```bash
axm doc_gate [PATH]
```

Run `axm <tool> --help` for the authoritative argument list generated from the
installed tool version. The CLI prints `ToolResult.text` and exits non-zero when
`ToolResult.success` is false; MCP and Python callers retain `ToolResult.data`.

## Python API

Auto-generated API reference (`mkdocstrings`) is available under **Python API**
in the monorepo-root documentation build (`axm-forge/docs`, which runs
`gen_ref_pages.py` across every workspace member). It is **not** generated by
this package's standalone `mkdocs.yml` (which delegates theme and plugins to
the root), so no in-package link is offered here — browse the root site's
`reference/axm_audit/` section, or read the docstrings directly in
`src/axm_audit/`.

### Formatters

- `format_test_quality_text(result, mismatches_only=False) -> str` — render
  the four base test-quality sections (private imports, pyramid, duplicates,
  tautologies) as plain text, plus `NO_PACKAGE_SYMBOL` and `FILE_NAMING`
  sections when present. With `mismatches_only=True`
  only the pyramid section is emitted, filtered to entries whose folder
  differs from the classified level.
- `format_test_quality_json(result) -> dict` — JSON superset returning
  `{score, grade, rules, clusters, verdicts, pyramid_mismatches,
  private_import_violations, no_package_symbol, file_naming}` (`rules` is
  the sorted list of every `TEST_QUALITY_*` rule id that was evaluated).
