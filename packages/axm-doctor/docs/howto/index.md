# How-to guides

Choose the task you need to accomplish.

- [Preflight an agent or DAG](preflight.md): interpret authentication, inspect
  structured reports and explicitly map a tool node's outputs.
- [Bootstrap a machine](bootstrap.md): review install plans, apply confirmed
  changes and inspect post-checks.
- [Python contracts](../reference/python.md): inspect provenance without
  credential values, handle account coordinates and understand failures.

Doctor detects and proposes; your application chooses the readiness policy.
Neither a generated report nor a completed bootstrap guarantees that an agent
session can start successfully.
