# Public Python API

The supported package surface is imported from `axm_smelt`.
Read [contracts and report semantics](../contracts.md) before interpreting savings.

::: axm_smelt
    options:
      members:
        - smelt
        - check
        - count
        - SmeltReport
        - Format
        - CounterBackend
        - __version__
      show_root_heading: true
      show_source: false
      show_if_no_docstring: true

## Version

`axm_smelt.__version__` is a string generated at build time, with a
`"0.0.0"` import-failure fallback in a source checkout.
